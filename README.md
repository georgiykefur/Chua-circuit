# Численное исследование цепи Чуа

Исследование движения в цепи Чуа двумя методами: **DOPRI5** и
**Адамса – Башфорта четвёртого порядка (AB4)**.

## Цель

Необходимо численно получить разные виды движения и научиться определять их

- регулярные колебания
- хаос (чувствительность к малому изменению начальных условий)
- колебания с растущей амплитудой

Все исследования выполняются двумя численными методами.
Используется алгоритм Бенеттина

## Как запустить

Скачать папку проекта и выбрать одну из команд

| Команда | Что делает |
|---|---|
| `make animation` | Считает обе траектории и открывает окно с анимацией |
| `make plots` | Считает траектории и показатели Ляпунова, сохраняет все графики |
| `make lyapunov` | Считает два показателя Ляпунова и выводит их в консоль |
| `make full` | То же, что `make plots`; анимацию не открывает |
| `make run` | Только считает две траектории |

## Как изменить параметры системы

Все параметры расчёта находятся в **`params.h`**. Выбор готового набора:

```cpp
const int preset = 2;
```

| Номер | Набор |
|---|---|
| 1 | `default` |
| 2 | `onecoil` |
| 3 | `periodic` |
| 4 | `staz` |
| 5 | `periodic2` |

## Структура проекта

- `params.h` — наборы параметров
- `chua.cpp` — система уравнений
- `dopri5.cpp`, `AB4.cpp` — формулы одного шага методов
- `main.cpp`, `main_ab.cpp` — расчёт и сохранение траекторий
- `benettin.cpp` — расчёт показателя Ляпунова
- `plot_results.py` — графики
- `animate.py` — анимация
